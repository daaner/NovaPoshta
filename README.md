## Встановлення
Встановіть пакет через Composer.

``` bash
composer require daaner/novaposhta
```


Якщо ви НЕ використовуєте autodiscover - додайте сервіс-провайдер у конфігураційний файл `config/app.php`.

```php
Daaner\NovaPoshta\NovaPoshtaServiceProvider::class,
```

Додайте фасад `NovaPoshta` до масиву в `config/app.php`:
```php
'NovaPoshta' => Daaner\NovaPoshta\Facades\NovaPoshta::class,
```

Опублікуйте конфіг і файли локалізації командою:
``` bash
php artisan vendor:publish --provider="Daaner\NovaPoshta\NovaPoshtaServiceProvider"
```


## Конфігурація

Після публікації ресурсів відредагуйте файл `config/novaposhta.php` і заповніть `.env` новими полями.

- Створіть акаунт на сайті [novaposhta.ua](https://novaposhta.ua)
- Скопіюйте `Ключ API` у налаштуваннях безпеки в розділі `Мої ключі API` і додайте у відповідний параметр у `config/novaposhta.php` або в .env файл
- `point` підтримується лише `json` (навряд чи додасться `xml`)
- `dev` - режим налагодження запитів. Записує в лог кожен запит до API Нової Пошти (не залишайте на продакшені) і додає в масив відповіді дані з ключем `dev` без перетворення, у тому вигляді, як їх повертає Нова Пошта
- читайте [документацію](https://daaner.github.io/NovaPoshta/) і користуйтеся


## Використання та API
- `setAPI($apiKey)` - встановлення API ключа, відмінного від значення за замовчуванням

```php
$cp = new Counterparty;
$cp->setAPI('391e241b2c********************e7');
```

- `getResponse($model, $calledMethod, $methodProperties, $auth = true)` - власне надсилання даних, якщо з'являться нові методи

```php
use NovaPoshta;
$model = 'TrackingDocument'; //потрібна модель
$calledMethod = 'getStatusDocuments'; //потрібний метод
$methodProperties = [
  //дані згідно з документацією
];
$np = new NovaPoshta;
$data = $np->getResponse($model, $calledMethod, $methodProperties, $auth = true);

dd($data);
```


## Підтримка моделей / методів
#### Хелпери (детальніші хелпери дивіться в документації до моделі)
Хелпери викликаються до головного методу звернення:

```php
$foo = new Common;
$list = $foo->getPaymentForms();

$bar = new Address;
$bar->setLimit(5)->setPage(2);
$cities = $bar->getCities();

dd($cities);
```

Дуже багато моделей мають у відповіді дубль російською. У деяких довідниках немає російської локалізації.
- `setLimit(100)` - ліміт записів у запиті
- `setPage(3)` - пагінація при ліміті
